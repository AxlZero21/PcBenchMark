# PcBenchMark

A simple PC benchmarking tool that shows your system specs and runs performance tests.

## Features

- CPU info (model, cores, threads, clock speed)
- RAM usage
- Storage info
- GPU detection
- Quick benchmark tests

## How to Use

Download `PcSpecsBenchMarkV2Official.exe` and run it.
