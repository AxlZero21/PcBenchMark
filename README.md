# 🖥️ PcSpecsBenchMark

A simple PC benchmarking tool that shows your system specs and runs performance tests.

---

## ✨ Features

- ⚡ CPU info (model, cores, threads, clock speed)
- 🧠 RAM usage (capacity, type, speed, slots used)
- 💾 Storage info (all drives with capacities)
- 🎮 GPU detection (model, VRAM, driver version)
- 🎨 8 Color Themes (click to cycle)
- 📋 Copy All specs to clipboard
- 🔧 Motherboard and BIOS info
- 🕒 OS and uptime info
- 🌐 Network adapters list

---

## 🚀 How to Use

Download `PcSpecsBenchMarkV2Official.exe` and run it.

**Controls:**
- Click **"Theme: X"** to change colors
- Click **"Copy All"** to copy specs to clipboard
